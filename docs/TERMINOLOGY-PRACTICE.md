# Terminology browser and What changes

The reference at `/resources/analysis-reference` is organised into six category buttons with full-text search over names, definitions, examples and possible analysis. Search clears the category filter to avoid hiding relevant results. `lib/terminology.ts` merges exact term-name duplicates from the reviewed `analysis-reference.json` snapshot while retaining each source reading and legacy term/group hash routes. The JSON remains the editable source snapshot; no automated OneDrive sync is introduced.

`/practice/what-changes` starts with seven original authored comparisons: diction, sentence boundaries, line breaks, image captions, typographic hierarchy, ordering, and a described resort-ad juxtaposition. No source novels or third-party extracts were reproduced. The historical sign chart remains credited to Wellcome Collection under its verified Public Domain Mark. Invented captions are explicitly labelled. The resort scenario is a description, not an actual image; feedback explicitly limits what can be inferred about unspecified visual details.

Exercises ask for a first interpretation, reveal a possible reading plus a complication, then invite transfer or revision. They are ungraded and use no AI requests. A check mark records that guidance was opened, not correctness. Student text stays in React state while switching exercises; export TXT or MD before navigating away or reloading. Exports separate student responses from authored guidance and preserve the typographic distinction in text. Every vocabulary link resolves to a canonical term.

The authoring model is `lib/what-changes.ts`. New comparisons should change a clear choice, provide enough context to reason about it, and support a defensible reading without presenting effects as automatic. Described scenarios are acceptable where a real visual would be impractical. Keep examples short and distinguish original or modified teaching material from quoted sources.
