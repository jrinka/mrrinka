# Assessment prompt references

`lib/assessment-reference.ts` contains short paraphrased task landmarks sent to the AI with each request. They are coaching context, not full rubrics, student work, or a source of marks. The student must still supply the text details being discussed. This keeps the public repository free of student submissions and licensed handouts.

The governing current reference is the IB's [2026 Language A examiner instructions](https://ibpublishing.ibo.org/exinst/apps/exinst/index.html?chapter=1&doc=EX_instructions_2026_e&part=8), which refer to the subject guides for first assessment 2026. In particular, Paper 2 distinguishes analysis of authorial choices (B1) from comparative analysis (B2); the IO is not a comparative task. The local `English/ENG Rubrics/IB Rubrics/IB English A Paper 2 Rubric.docx` confirms five 5-point criteria (A, B1, B2, C, D), for 25 marks rather than the older 30. Recheck these sources when a later assessment guide takes effect.

Teacher material consulted in OneDrive, used for the teaching emphasis rather than copied into prompts:

- `04 IB Lit/04 HL Essay/HLE Criteria Unpacked v2.pdf`
- `English/ENG Rubrics/IB Rubrics/IB English A IO Rubric Lang Lit.docx` and `IB English A IO Rubric Lit.docx`

Some local rubric files reflect the earlier assessment guide. Where they differ from the 2026 examiner instructions, use the current IB guidance. Do not feed full OneDrive documents or student assessment files to the model. Update the summaries deliberately when classroom guidance or IB rules change.
