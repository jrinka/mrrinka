# Analysis reference

`lib/analysis-reference.json` is the reviewed publication snapshot for `/resources/analysis-reference`.

Sources: Mr Rinka’s `IB_LangLit_50_Terms.docx` and `IB LL Image Analysis Guide v2.docx` in the Resource Library’s Skills + Reference folder. The originals and the image guide’s companion PDF were updated on 24 September 2026. Preserve table categories and all 50 literary/rhetorical terms and 61 visual terms when refreshing this snapshot.

The heading is **Possible analysis**. Retain common effects as useful starting points; qualify deterministic claims where context can complicate or reverse them. Camera angle, typography, colour, modality and gaze need contextual interpretation. Do not turn every definition into a hedge or imply that all readings are equally supported.

The website does not automatically sync with OneDrive. Future document revisions require an explicit reviewed update to this snapshot. Student-facing entries use native expandable details and stable anchors; no AI or student data is involved.
