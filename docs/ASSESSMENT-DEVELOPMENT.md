# Assessment development notes

## Future segment: organization that develops an argument

Requested 25 September 2026. Plan this for a later session; the full segment is not yet built.

Students often rely on a three-part thesis and produce paragraphs that could be rearranged without changing the argument. Keep three-part plans as a valid option, while teaching students how to make the reasoning develop from paragraph to paragraph.

Show achievable examples of several structures: following a text’s development, establishing and then complicating a reading, tracing cause and consequence, and building a comparison through connected claims. Explain when each structure suits the question and evidence. Avoid replacing one mandatory formula with another.

Include an exercise that asks students to reorder paragraphs, explain why one must precede another, and revise a paragraph so it changes or extends the argument. Pair a list-like response with a developing response using the same evidence. Connect the work to Criterion C for each assessment without promising that a structure earns a particular mark.
